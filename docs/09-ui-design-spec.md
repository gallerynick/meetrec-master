# 09 · UI 设计规范

> 依据 Apple Human Interface Guidelines（apple-hig skill v1.0.0），映射到 PySide6 / Qt 实现。
> 适用范围：macOS 与 Windows 共用同一套设计令牌与布局规则，仅平台特定部分（菜单、快捷键修饰键、窗口按钮）分叉。

---

## 1. 设计原则

Apple HIG 的核心原则在本项目中的落地：

| HIG 原则 | 本项目的落地 |
|---|---|
| **Consistency（一致性）** | 全部控件用 PySide6 原生样式 + 统一 QSS 覆盖；同类操作在所有页面用同样的按钮位置与文案；不混用两套视觉语言 |
| **Feedback（反馈）** | 每个用户动作 < 100 ms 内有视觉响应；长任务显示进度（可取消）；异步结果用明确的成功 / 失败状态呈现 |
| **User Control（用户控制）** | 破坏性操作（删除、覆盖、重新转写）必须可撤销或二次确认；所有自动改动（热词校正）可逐条撤销 |
| **Familiarity（熟悉度）** | 遵循平台惯例：macOS 红绿灯左上、Windows 窗口按钮右上；设置用侧边分类 + 即时生效（无「确定 / 取消」） |
| **Meaningful Imagery（有意义的图像）** | 图标只表达功能，不用装饰性插图；关键词分组用色相区分而非形状 |

### 1.1 本项目特有的两条

1. **可信优先于炫技**：热词校正是「系统替用户改文字」，必须让用户随时看见改了什么、为什么改、如何撤销。任何自动化都配一个可见的撤销入口。
2. **进度可见**：ASR 转写与 AI 请求都是长任务，必须显示阶段名、进度百分比、预计剩余与取消按钮，禁止只转圈。

## 3. 应用窗口结构

### 3.1 主窗口布局

```text

├──────────────┬───────────────────────────────────────────────────┤
│              │                                                   │
│  会议库       │                内容区                             │
│  ┌────────┐  │   （随侧边导航切换的视图）                        │
│  │+ 新会议│  │                                                   │
│  └────────┘  │                                                   │
│              │                                                   │
│  ● 最近的    │                                                   │
│  ● 产品评审  │                                                   │
│  ○ 需求讨论  │                                                   │
│  ○ 事故复盘  │                                                   │
│              │                                                   │
│ ─────────── │                                                   │
│  关键词库    │                                                   │
│  设置        │                                                   │
└──────────────┴───────────────────────────────────────────────────┘
   232 pt              弹性
```

| 区域 | 规格 |
|---|---|
| 侧边栏 | 固定 232 pt，可折叠至 56 pt（仅图标）；折叠状态记忆 |
| 内容区 | 弹性；视图切换用交叉淡入（150 ms），不做滑动转场 |
| 标题栏 | macOS 用统一标题栏（Unified Title Bar），工具按钮右对齐；Windows 用系统标题栏 |
| 状态栏 | 仅长任务时出现，高 28 pt，显示阶段 + 进度 + 取消 |

### 3.2 导航模式

采用 **Sidebar Navigation**（HIG 推荐的多项主导航），理由：会议库是列表型主内容，需要常驻可访问；设置与关键词库是次级入口，放在侧边栏底部。

| 项 | 规则 |
|---|---|
| 选中态 | 圆角矩形底色（accent 12%）+ 文字 accent 色 |
| 悬停态 | card-bg 底色，80 ms 过渡 |
| 图标 | 18 × 18，线性风格，stroke 1.5 pt |
| 排序 | 主导航按使用频率；「设置」永远在最底部 |
| 空态 | 会议库为空时显示引导文案 + 「新建会议」主按钮 |

## 4. 视图规格

### 4.1 会议详情视图（5 步流程条）

会议打开后顶部显示流程条，指示当前所处阶段：

```text
  ① 录音/导入 ── ② 转写 ── ③ 关键词校对 ── ④ 生成纪要 ── ⑤ 导出
      完成          进行中        待开始         待开始        待开始
```

| 状态 | 视觉 |
|---|---|
| 已完成 | 实心圆 + success 色 + ✓ |
| 进行中 | 实心圆 + accent 色 + 旋转环 |
| 待开始 | 空心圆 + border 色 |
| 可点击 | 已完成的步骤可点击回看 |

#### 步骤 1 · 录音 / 导入

```text
┌─────────────────────────────────────────────┐
│  会议标题：_______________          [编辑]   │
│                                             │
│        ┌─────────────────────┐              │
│        │      ●              │              │
│        │   00:12:34          │              │
│        │   ▁▂▄▆▇▆▄▂▁        │  ← 实时电平表 │
│        └─────────────────────┘              │
│                                             │
│      [ ⏺ 开始 ]  [ ⏸ 暂停 ]  [ ⏹ 停止 ]     │
│                                             │
│  ── 或导入已有音频 ──                        │
│  [ 📁 选择文件 ]   拖拽音频到此处             │
│                                             │
│  支持：WAV · MP3 · M4A · AAC · FLAC          │
│  上限：2 GB                                  │
└─────────────────────────────────────────────┘
```

| 元素 | 规格 |
|---|---|
| 录音按钮 | 直径 72 pt 圆形，accent 色，按下态缩放 0.94；录音中显示红色脉冲环 |
| 电平表 | 48 段柱状，RMS → dBFS（-60 到 0）映射，20 Hz 刷新 |
| 计时器 | mono 字体 34 pt，tabular figures 防抖动 |
| 导入区 | 拖拽时虚线边框 accent 色；不支持格式时 error 色 + 原因 |
| 空录音 | 时长 < 1 秒时停止按钮置灰并提示 |

#### 步骤 2 · 转写

```text
┌─────────────────────────────────────────────┐
│  模型：[large-v3-turbo ▾]  语言：[中文 ▾]    │
│  计算：[int8 ▾]       [ 取消 ]               │
│                                             │
│  ██████████████░░░░░░░░  47%   剩余 2 分 10 秒 │
│  阶段：基线转写 / 共 4 阶段                   │
│                                             │
│  已识别片段：                                │
│  [00:00] 会议开始。今天主要讨论……            │
│  [00:12] 先说背景。MeetRec Master 目前……     │
│  [00:34] ……                                  │
└─────────────────────────────────────────────┘
```

| 元素 | 规格 |
|---|---|
| 阶段进度 | 4 阶段分段条（基线 / 缺口分析 / 定向重解码 / 后处理），当前阶段高亮 |
| 增量文本 | 转写完成即追加显示，不等全部结束 |
| 取消 | 随时可取消；取消后保留已转写部分并提示 |
| 模型缺失 | 显示下载卡片（大小、进度、开始下载按钮），不阻断 UI |

#### 步骤 3 · 关键词校对

```text
┌─────────────────────────────────────────────┐
│  关键词命中 47 个   已校正 23 处   [ 全部撤销 ]│
│  强度：[平衡 ▾]  分组：[全部 ▾]              │
│                                             │
│  [00:00] 会议开始。今天主要讨论…………        │
│  [00:12] 先说背景。[MeetRec Master]✓ 目前有… │
│  [00:34] 这个方案[张一鸣]✓他们会怎么看，      │
│          还有 [CTranslate2]≈这边的性能……      │
│  [01:02] ……[张伟]～（疑似，未自动校正）        │
└─────────────────────────────────────────────┘
```

角标语义（与 05 章 §9 一致）：

| 角标 | 来源 | 颜色 |
|---|---|---|
| ✓ | 别名精确匹配 | success |
| ≈ | 模糊相似度校正 | accent |
| ⇄ | Stage 3 定向重解码改动 | accent |
| ～ | 歧义未校正 | warning |

- 悬停角标 → 气泡显示：原文 → 校正后 · 来源 · 置信度 · 拼音/编辑分
- 点击角标 → 弹出「撤销 / 保持 / 登记为别名 / 加入不校正名单」
- 时间戳可点击 → 音频定位播放（±5 秒）

│  服务商：[DeepSeek 主账号 ▾]  模型：[chat ▾]  │

| 元素 | 规格 |
|---|---|
| 章节校验 | 生成后逐章节校验，缺失章节用 warning 标出并提示重试 |
| 版本 | 每次生成追加一个 run，「上一版」可回退 |

## 5. 设置视图

### 5.1 布局

左侧分类列表 + 右侧表单（HIG 的 Settings/Preferences 模式）：

| 分类 | 内容 |
|---|---|
| 通用 | 界面语言、主题、启动时检查新版本 |
| ASR | 默认模型、默认语言、计算类型、模型目录、VAD、beam_size |
| 关键词 | 开关三项（Stage 3 / Stage 4 / 别名）、纠错强度、预算、不校正名单 |
| AI | 默认服务商、默认温度、Max Tokens、超时、重试次数 |
| 录音 | 输入设备、输出格式 |
| 数据 | 回收站天数、日志级别、导出 BOM |
| 关于 | 版本、许可（含模型许可清单）、诊断包导出、创建快捷方式（Windows） |

### 5.2 规则

1. **即时生效**：修改即写入 config.json，无「确定 / 取消」按钮。
2. **可撤销**：支持 ⌘Z 撤销上一次设置变更。
3. **重置**：每个分类底部有「恢复默认值」。
4. **危险操作**：「清除全部数据」「重置密钥」需输入确认词，不用简单确认框。

## 6. 组件规格（PySide6 映射）

| 用途 | PySide6 控件 | 规格 |
|---|---|---|
| 主按钮 | QPushButton + QSS | 高 28，圆角 8，accent 底 + 白字；按下 accent-pressed；禁用 text-tertiary |
| 次按钮 | QPushButton | 高 28，圆角 8，card-bg 底 + border 描边 + text-primary |
| 危险按钮 | QPushButton | error 色文字，hover 时 error 底 12% |
| 图标按钮 | QToolButton | 28 × 28，图标 16，无文字；tooltip 必填 |
| 录音大按钮 | 自绘 QPushButton | 直径 72，圆形，accent 底；录音中显示红色脉冲环（QPropertyAnimation） |
| 输入框 | QLineEdit | 高 28，圆角 4，border 描边；focus 时 accent 描边 2 pt；placeholder text-tertiary |
| 多行输入 | QPlainTextEdit | 圆角 4，内边距 8；行高 1.5 |
| 下拉 | QComboBox | 高 28，圆角 4，右侧 chevron 图标 |
| 开关 | QCheckBox 自绘 | 44 × 24 轨道 + 20 圆点；开启 accent 底；100 ms 过渡 |
| 滑块 | QSlider | 高 4 轨道，12 圆点把手 |
| 分段 | QPushButton 组 | 用于「强度」三选一，选中项 accent 底 |
| 表格 | QTableWidget | 行高 32，表头 text-secondary 11 pt，斑马纹 card-bg |
| 树 / 分组 | QTreeWidget | 用于关键词库分组；缩进 16 |
| 进度条 | QProgressBar | 高 6，圆角 3，accent 填充；不确定态用分段滑动动画 |
| 提示气泡 | QToolTip + 自绘 | 圆角 8，card-bg 底，阴影 8 pt 模糊 |
| 对话框 | QDialog | 圆角 12，宽 480–640，内容区最大高 560 超出滚动 |
| 空态 | QLabel + QPushButton | display 字号标题 + 说明 + 主按钮，居中 |
| 通知 | 自绘 QFrame（不用 QMessageBox 除非致命） | 右上角滑入，4 秒自动消失，可手动关闭 |

### 6.1 禁用态

所有禁用控件统一：文字 text-tertiary，背景不变，**不加斜纹**（HIG 建议保持视觉稳定）。禁用必须配 tooltip 说明原因。

### 6.2 焦点与键盘导航

1. Tab 顺序按视觉阅读顺序（上到下、左到右）。
2. 焦点环：2 pt accent 描边 + 2 pt 外边距，**不得隐藏**（可访问性）。
3. 对话框内支持 Esc 取消、Return 触发主操作。
4. 列表支持上下箭头移动、Space 选中、Enter 打开。

## 7. 交互与反馈

### 7.1 响应时间预算

| 动作 | 预算 | 超时表现 |
|---|---|---|
| 点击按钮的视觉响应 | < 100 ms | 立即按下方按下态 |
| 打开对话框 | < 200 ms | — |
| 切换视图 | < 300 ms | 交叉淡入 150 ms |
| 保存设置 | < 50 ms | — |
| 关键词纠错（1 小时转写） | < 3 s | 显示进度 |
| AI 请求 | 无预算 | 显示阶段 + 重试次数 |

### 7.2 长任务状态条

底部状态条（高 28 pt）内容：

```text
[阶段图标] 基线转写 · 47% · 剩余约 2 分 10 秒          [取消]
```

| 阶段名 | 文案 |
|---|---|
| 基线转写 | 正在识别语音（不注入热词） |
| 缺口分析 | 正在分析关键词缺口 |
| 定向重解码 | 正在复核候选区域（3/12） |
| 后处理纠错 | 正在校正关键词 |
| AI 请求 | 正在生成纪要 · 第 2/3 次尝试 |
| 导出 | 正在导出 · 62% |

### 7.3 错误呈现

| 类型 | 呈现方式 |
|---|---|
| 可恢复错误（网络、限流） | 内联错误条 + 「重试」按钮，不弹窗 |
| 需要用户修正（Key 无效、格式不支持） | 内联错误条 + 引导到设置页的链接 |
| 破坏性操作前 | 确认对话框（列出将影响的范围） |
| 致命错误（数据目录不可写） | 模态对话框，必须处理后才能继续 |

**禁止**：只弹一个红色 QMessageBox 而无任何可操作指引。每条错误必须回答「用户现在能做什么」。

### 7.4 空态与引导

| 场景 | 文案要点 |
|---|---|
| 首次启动 | 「开始第一场会议」+ 录音 / 导入两个主按钮 + 三步流程说明 |
| 会议库为空 | 「还没有会议」+ 新建按钮 |
| 关键词库为空 | 「还没有关键词」+ 添加按钮 + 导入示例库链接 |
| 未配置服务商 | 「还没有配置 AI 服务商」+ 添加按钮 + 填写三字段说明 |
| 模型未下载 | 下载卡片（体积 / 预计时间 / 开始下载） |

## 9. 可访问性

| 要求 | 实现 |
|---|---|
| 对比度 | 正文与背景 ≥ 4.5:1（WCAG AA）；大字号 ≥ 3:1。暗色主题必须逐色校验 |
| VoiceOver / 屏幕阅读器 | 所有控件设置 accessibleName；按钮、开关、进度条设置 accessibleDescription；状态变化用 QAccessible 事件广播 |
| 全键盘可达 | 所有功能可不依赖鼠标完成（见第 8 章） |
| 焦点可见 | 焦点环不得移除；z-order 保证焦点环在顶层 |
| 动态字体 | 支持系统字体缩放（Qt 的 fontDpiChange 需重算布局） |
| 减弱动效 | 检测系统「减少动态效果」设置（macOS accessibilityReduceMotion / Windows 动画开关），关闭脉冲环与滑入动画 |
| 高对比度 | Windows 检测 High Contrast Mode，切换为高对比配色 |
| 不靠颜色传达 | 状态除颜色外配图标 / 文字（✓ ≈ ⇄ ～ 角标即是此设计） |

## 11. 视觉资产与许可

| 资产 | 要求 |
|---|---|
| 图标字体 | 使用 SF Symbols（macOS 系统自带，随系统授权）或自绘 SVG；**不使用**付费图标库 |
| 自绘 SVG | 统一 24 × 24 viewBox、stroke 1.5、圆角线帽；命名 kebab-case |
| 应用图标 | macOS .icns（1024 起）、Windows .ico（256 起）；风格为圆角矩形 + 品牌色 |

| 第三方许可 | 全部随包分发 LICENSES.txt（含模型权重许可） |

## 12. UI 验收清单

| # | 项 | 方法 |
|---|---|---|
