# 12 · 实施路线图与验收

---

## 1. 里程碑总览

| 里程碑 | 主题 | 核心交付 | 退出标准 |
|---|---|---|---|
| **M0** | 项目骨架 | 仓库结构、包管理、CI 骨架、日志与配置、i18n 框架 | CI 空跑全绿；pytest 可跑 |
| **M1** | UI 骨架 | 主窗口、侧边导航、5 个视图占位、主题、窗口几何记忆 | 双平台可启动，无崩溃 |
| **M2** | 录音与导入 | Recorder 状态机、电平表、音频导入、格式探测、会议目录创建 | 录音产物可播放；5 种格式导入成功 |
| **M3** | 本地转写 | faster-whisper 封装、模型下载缓存、进度、分块、**baseline 模式** | 3 段样本转写成功；模型缺失与断网处理正确 |
| **M4** | 关键词优先识别 | 关键词库 CRUD、缺口分析、**定向重解码**、后处理纠错、别名、撤销、高亮 | 召回率 ≥ 90% 且普通文本 WER 退化 == 0 |
| **M5** | AI 纪要 | 双协议适配、重试退避、章节解析、模板编辑、纪要视图 | 各跑通 1 家 OpenAI 兼容 + 1 家 Anthropic 服务商 |
| **M6** | 设置与导出 | 设置中心全项、导出矩阵、会议库、回收站、诊断包、i18n 完整 | 全部设置项生效；导出 6 种组合正确 |
| **M7** | 打包发布 | PyInstaller spec、CI matrix、ad-hoc 自签名、sha256 校验和、冒烟、用户手册（**无商业签名**，ADR-012） | 发布门禁 G1–G8 全过 |

> 依赖顺序：M0 → M1 → M2 → M3 → M4 → M5 → M6 → M7。M4 与 M5 在 M3 完成后可并行。

## 5. 风险与应对

| 风险 | 概率 | 影响 | 应对 |
|---|---|---|---|
| 关键词召回率达不到 90% | 中 | 核心差异化失效 | 四阶段架构 + 别名表；M4 结束时若未达标，先降阈值至「激进」预设并扩充别名，再评估是否需要补充样本 |
| Stage 3 重解码导致总耗时超预期 | 中 | 用户体验 | 候选预算从 15% 降到 10%；小区域合并；提供「仅基线 + 后处理」快速模式 |
| large-v3-turbo 在低配 CPU 上过慢 | 中 | 默认体验差 | 自动探测 CPU 性能，低于阈值时建议切换到 small 并提示 |
| 未签名产物被企业 EDR / 杀毒软件主动拦截 | 中 | 部分用户无法运行 | 接受 SmartScreen 警告；EDR 拦截时申请白名单或改用 zip 内运行；触发 ADR-012 重新启用条件时补签 |
| 准确率样本与真实使用场景分布不同 | 中 | 验收结论偏差 | 3 段样本尽量覆盖例会 / 评审 / 电话会议三种场景 |
| PyInstaller 打包二进制缺失 | 中 | 安装包不可用 | spec 显式 collect + 构建后 smoke_test.py 强制门 |
| 不同网关字段差异导致请求失败 | 高 | 用户配置挫败 | 字段兼容开关 + 自动降级 + 明确中文提示 |
| 用户手动编辑后 offset 错位 | 高 | 校正记录失效 | raw / text 双存 + text_edited 标记 + 以 raw 重算 |
| 钥匙串不可用 | 低 | 密钥无法安全存储 | ADR-007 降级方案 + 明确提示 + 迁移入口 |
| 模型下载被网络阻断（企业内网） | 中 | 首次使用失败 | 应用内模型管理页支持手动放置模型目录（ADR-009 第 4 条）；**不提供离线装机版**（已否决） |

## 6. 完成定义（DoD）

v1.0.0 发布需同时满足：

1. 第 3 章硬约束验收清单 C1–C9 全部勾选。
2. 附加验收项 A1–A5 全部勾选。
3. Bundle ID 已定（io.meetrec.master）；准确率样本在 M4 验收前提供即可（非阻塞）。
4. 准确率报告满足：召回率 ≥ 90% 且普通文本 WER 退化 == 0。
5. 用户手册与 Release Notes 完成。
